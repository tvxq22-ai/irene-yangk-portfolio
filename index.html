算法与图表解读 · 为什么用 KMeans？数据源：2000+ 条官方新闻 + 社群发帖受害者记录
  • 为什么用 KMeans：要回答「什么样的人容易被什么骗」，前提是先把人分群——用无监督聚类把碎片化的受害者特征标准化后自动划分为画像组，让反诈宣传能针对不同人群定制内容而非一刀切
  • ① 肘部法则：簇内误差随 K 增大而下降、速率放缓的「拐点」落在 K=3，即受害人群最佳划分为 3 组
  • ② 画像结论：企业青年（电商场景盲目相信、多小额试水）／学生青年（集中于教育培训、求职类诈骗）／中年与无业（虚假投资、大额投入，风险最高）
  • ③ 预测 Demo：基于画像训练 RandomForest 分类模型，输入年龄 / 职业 / 经济状况 / 资金行为 / 决策特征 / 荣格心理，即可实时预测该人群易被哪类诈骗盯上，把分析结论变成可交互工具，服务反诈预警与科普选题（Demo.ipynb 可完整运行）

# 深度过滤：只保留高质量样本进行画像
df_model = df_raw[
    (df_raw['age_group'] != 'Unknown') &
    (df_raw['occupation'] != 'Unknown') &
    (df_raw['decision_trait'] != 'Unknown') &
    (df_raw['fraud_category'] != 'Other Scam')
].copy()

# One-Hot 编码聚类特征
cluster_features = ['age_group', 'occupation', 'economy',
                        'fund_behavior', 'decision_trait']
df_enc = pd.get_dummies(df_model[cluster_features]).astype(int)

# K-Means 聚类（K=3，让画像更典型）
K = 3
kmeans = KMeans(n_clusters=K, random_state=42, n_init=10)
df_model['Cluster'] = kmeans.fit_predict(df_enc)

# 自动生成画像报告（每簇取最显著特征）
for i in range(K):
    g = df_model[df_model['Cluster'] == i]
    top_age, top_occ = g['age_group'].mode()[0], g['occupation'].mode()[0]
    top_dec  = g['decision_trait'].mode()[0]
    top_scam = g['fraud_category'].mode()[0]
    report.append(f"Group {i}: {top_age} {top_occ} | Weakness: {top_dec} | High Risk: {top_scam}")
